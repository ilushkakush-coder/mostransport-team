# Вакансия мечты — «Нрав или не нрав?»

Статический Telegram Mini App с 30 карточками-вопросами и свайпами: вправо — «нрав», влево — «не нрав». Интерфейс оформлен в белом, сером и чёрном цветах; карточки содержат только текст. Следующая карточка появляется после короткой анимации, сохранение выполняется в фоне.

## Файлы проекта

- `index.html` — интерфейс карточек и отправка открытия/ответов.
- `Code.gs` — Apps Script: создаёт таблицу, принимает события и проверяет подпись Telegram `initData`.
- `PROJECT_GUIDE.md` — подробные шаги настройки, публикации и дальнейших обновлений.

Telegram-бот отвечает на `/start` приветствием и inline-кнопкой `Открыть приложение`. Обработчик и регистрация webhook находятся в `Code.gs`; токен бота и секрет webhook хранятся в свойствах Apps Script.

## Google Таблица и Apps Script

Проект Apps Script **«команда транспорта»** принимает валидированные события Telegram Mini App. Таблица результатов хранится на Google Drive владельца и содержит вкладки `Sessions`, `Responses` и `Summary`:

- `Sessions` записывает дату открытия, Telegram ID и ID сессии.
- `Responses` записывает каждый ответ вместе с Telegram ID и конкретным ID/текстом вопроса.
- `Summary` автоматически считает «Нрав» и «Не нрав» по каждому вопросу. Прежние значения учитываются при подсчёте сохранённых ответов.

Публичный endpoint исполняется от имени владельца, но принимает записи только с корректной подписью Telegram `initData` не старше 24 часов. Его адрес подключён в `APPS_SCRIPT_URL`. Токен хранится в свойствах Apps Script, не в репозитории.
